# d-mode-skill
D Mode 使用方法

你只需要說「用 D Mode」，再附上故事、分鏡、提示詞或影片。我會根據資料進入適合的步驟，不要求你每次從頭開始。

1．從大綱逐步設計影片
「用 D Mode，這是故事大綱，請逐步提供選項，確認分鏡後才生成提示詞。」

流程：大綱 → 場景 → 人物與觀眾情緒 → 分鏡方案 → 整場連接 → 你確認 → 完整提示詞。
每輪集中處理一項主要決定，通常提供 2–3 個選項及推薦理由。

2．尋找適合某種情緒的拍法
「用 D Mode，我想表現緊張的追逐，找出三個拍法並解釋原因。」

我會從方法庫選擇不同的表達方式，說明適用條件與限制，而不是把「緊張」一律變成手持或快剪。

3．改善單一鏡頭
「用 D Mode，主角在門前猶豫，請提供三種拍法，暫時不要寫提示詞。」

我會比較構圖、表演、視點、運鏡、停頓及資訊揭示，並考慮前後鏡如何銜接。

4．檢查整場戲
「用 D Mode，檢查以下分鏡的運鏡、空間和情緒推進，先不要修改。」

適合提供分鏡表或整組提示詞。檢查包括方向、視線、人物位置、動作連戲、節奏、重複資訊及轉場；一鏡到底也可以檢查。

5．檢查及修改現有提示詞
「Check Prompt Skill：保留故事與已確認設定，檢查並修改以下提示詞。」

預設交付問題摘要及完整標準化新版。若只想了解問題，補上「只檢查，不改寫」。

6．從已確認內容生成新提示詞
「Build Prompt Skill：根據以下已確認分鏡，生成完整提示詞。」

固定六部分：生成任務、主要主體、場景與環境狀態、情緒目標、視覺風格、分段腳本。
若影像感覺未確定，先讓你選擇；之後由我配置攝影機、焦距、光圈及對焦。每份獨立提示詞中，每項資產只引用一次。

7．診斷已生成的影片
「用 D Mode，這是影片、當次提示詞和參考圖，請分析問題並提出修改方案。」

我會在可讀取的範圍內，以時間碼指出問題，區分看見的結果與推測原因，再建議剪輯修補、局部重生成或修改設計。涉及實質創意改動時先讓你確認。

8．查閱方法庫
「用 D Mode，找出適合多人對話的方法。」
「展開 B1-M012，說明做法、限制及來源。」
「比較兩種揭示新資訊的運鏡方式。」

可以按情緒、敘事功能、技術或表達機制查找，不需要記住編號。

常用回覆指令
- 「選 B」／「混合 A 和 C」／「三個都不合適」。
- 「這項已確認，不用再問」。
- 「其餘由你提出建議，先列為提案」。
- 「通過，生成提示詞」。
- 「只修改第二鏡，其他設定保留」。
預設使用繁體中文書面語，角色對白則保留你指定的語言。方法建議不等於已批准，也不代表生成效果已經驗證。
